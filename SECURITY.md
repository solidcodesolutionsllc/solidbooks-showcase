# Security

## Scope

This repository is an engineering showcase. It contains self-contained code
samples that run entirely on your machine against an in-memory database. It
holds no credentials, connects to no external service and has no access to
the SolidBooks production system or to any business or customer data.

## Reporting a vulnerability

If you believe you have found a security issue in this repository, or in a
Solid Code Solutions LLC product, please report it privately through the
contact options at [solidcodesolutionsllc.com](https://solidcodesolutionsllc.com)
rather than opening a public issue. Please include enough detail to
reproduce the problem. We will acknowledge your report and keep you informed.

Please do not test against systems you do not own.
